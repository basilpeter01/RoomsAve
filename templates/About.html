About RoomsAve

A hotel room booking & management system

🏨

What is RoomsAve?

RoomsAve is a full-stack hotel room management system that allows guests to browse available rooms, make bookings, and process payments — all through a clean, intuitive web interface.

🎓

Built For

This project was created as part of a Database Management Systems (DBMS) course to demonstrate practical implementation of relational databases, backend APIs, and frontend integration.

✨

Key Features

  • Browse and search available rooms with filters
  • User registration & login
  • Room booking with date selection
  • Booking management — view, pay, or cancel
  • Auto-checkout when stay period ends
🛠️

Tech Stack

Python Flask MySQL HTML CSS JavaScript
🔐

Security

Passwords are hashed using PBKDF2/Scrypt via Werkzeug. User sessions are managed server-side with Flask's secure session handling.
